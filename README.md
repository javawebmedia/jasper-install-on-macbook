# Cara Install Jasper di Macbook
Berikut langkah-langkah install Jasper di Macbook. Asumsikan kita memakai MAMP. Boleh ya pakai folder lain.

# Mengecek Versi Java dan Maven
Cek versi Java:
<code>
java -version
</code>

Cek versi Javac:
<code>
javac -version
</code>

Cek versi Maven:
<code>
mvn -version
</code>
